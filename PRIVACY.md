# Privacy Policy — Quantelix Course Uploader

_Last updated: November 5, 2026_

## What this application is

Quantelix Course Uploader is a private, owner-operated automation tool. It is used by exactly one person — the owner of the YouTube channel "The Architect's AI Workshop" — to upload that owner's own videos to that owner's own channel through the YouTube Data API. The application is not distributed to, or used by, any other person. It has no other users, collects no data from any other person, and offers no sign-in to the public.

## Data the application accesses

With the channel owner's authorization, the application accesses only what uploading requires:

- The owner's YouTube channel identity (to confirm it is uploading to the correct channel).
- Video files, titles, descriptions, thumbnails, and caption files that the owner created, which the application transmits to YouTube at the owner's direction.

## How data is handled

- OAuth credentials are stored locally, on the owner's own machine, in a permission-restricted folder. They are never transmitted to any party other than Google's own authorization and API endpoints.
- No data is sold, shared, rented, or disclosed to any third party.
- No analytics, advertising, tracking, or profiling of any kind is performed.
- Video and caption content passes through the application only in transit to YouTube; the application keeps no copy beyond the owner's own local files.

## Data retention and deletion

Because the application serves only its owner, there is no user data to retain or delete. The owner may revoke the application's access at any time from the Google Account permissions page (myaccount.google.com/permissions), which immediately invalidates the stored credentials.
